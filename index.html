1. Introduction to Java & WORA

Java was developed by Sun Microsystems in 1995. It is a premier, high-level, class-based, and object-oriented programming language designed for backend systems, enterprise software, big data, and Android applications.

High-Level & OOP Easy to read for humans; structured around classes (blueprints) and objects (data + behaviors).
Write Once, Run Anywhere Java compiles code into intermediate bytecode. The JVM (Java Virtual Machine) runs this bytecode on any OS.
Secure & Robust Eliminates memory pointers and relies on automated Garbage Collection to prevent memory leaks and crashes.
Program Structure Example 
package myfirstproject;

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
💡 Simple Breakdown / Paliwanag

• package: Parang folder sa computer kung saan naka-store ang related files.

• public class Main: Blueprint ng program. Strict Rule: Dapat parehong-pareho ang pangalan ng class sa file name (Main.java).

• public static void main(String[] args): Ito ang "Green Play Button" o entry point ng Java program. Kapag wala ito, hindi tatakbo ang code.

• System.out.println(): Ang nagpapadala ng text papunta sa screen at lumilipat sa kasunod na linya.

2. Naming Conventions & Rules

Java is case-sensitive (capital 'A' is distinct from lowercase 'a'). We use standard naming patterns so other developers can read our code cleanly.

Type Convention Incorrect Example Correct Example
Class Name UpperCamelCase (PascalCase) studentprofile, student_profile StudentProfile
Variable / Method lowerCamelCase Fullname, full_name fullName, getScore()
💡 Code Indentation Note

Ang mga curly braces { } ay nagdidikta ng scope o boundary ng code. Lahat ng nasa loob ng braces ay pinalalayo ng 4 spaces (1 tab) pakanan para madaling makita kung saan nagsisimula at nagtatapos ang isang method.

3. Input/Output (I/O) & Default Streams

System.out Standard Output Pipe. Used to write regular text to the screen console.
System.in Standard Input Pipe. Used to read raw keystrokes from the user's keyboard.
System.err Standard Error Pipe. Used to output warnings/errors (highlights in red in NetBeans).
Scanner I/O Demo 
import java.util.Scanner;

public class CrushCalculator {
    public static void main(String[] args) {
        Scanner inputReader = new Scanner(System.in);
        
        System.out.print("Enter Crush's name: "); // Leaves cursor on same line
        String crushName = inputReader.nextLine();     // Reads full string line
        
        System.out.println("Compatibility: 99.9% with " + crushName);
        System.err.println("[WARNING]: Do not assume."); // Error stream
    }
}

4. Data Types & Typecasting

int age = 20;

Whole numbers without decimal places.

double price = 99.95;

Floating-point numbers with decimals.

char grade = 'A';

Single character inside single quotes ' '.

boolean isSingle = true;

Logical state: true or false.

String name = "Maria";

Reference type! Sequence of characters enclosed in double quotes " ".

Typecasting (Conversion)
Implicit (Widening)

Automatic conversion from small to large type (e.g., int to double). No precision loss.

double b = 10; // Result: 10.0
Explicit (Narrowing)

Manual cast needed (large to small type). Decimals are lost/truncated!

int p = (int) 99.95; // Result: 99

• Modulo (%): Returns the division remainder. 13 % 6 = 1.

6. Bitwise Operators & Binary Mechanics

A bit (binary digit) is either 0 (OFF) or 1 (ON). 8 bits equal 1 Byte. Bitwise operators work directly on binary digits.

Bitwise Calculations (a = 5 [0101], b = 3 [0011])
a & b (AND) 1 (0001)
a | b (OR) 7 (0111)
a ^ b (XOR) 6 (0110)
5 << 2 (Left Shift) 20 (5 * 2²)

7. Precedence & Worked Step-by-Step

Worked Problem: int result = 10 + 2 << 1 & 15;

1. Addition (+) has higher priority: 10 + 2 = 12 ➔ 12 << 1 & 15

2. Shift (<<) executes next: 12 << 1 = 24 ➔ 24 & 15

3. Bitwise AND (&): 24 (11000) & 15 (01111) = 8 (01000)

Final Output: result = 8

8. Decision Making & Modern Switch

Traditional Switch (case :)

Requires explicit break; statements to avoid fall-through bugs into subsequent cases.

Modern Arrow Switch (case ->)

No fall-through! Evaluates directly and can return a value using yield in multi-line blocks.

Modern Switch Syntax
String day = "MONDAY";
String type = switch (day) {
    case "MONDAY", "FRIDAY" -> "Weekday";
    case "SATURDAY" -> {
        System.out.println("Weekend!");
        yield "Rest Day";
    }
    default -> "Invalid";
};
